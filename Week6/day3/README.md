# Day 3: Sequential AI Workflow in n8n

## Task Description
Create an AI workflow where multiple LLM steps process data sequentially before producing a final output.

## Overview
This directory contains an exported n8n workflow (`sequential_ai_workflow.json`) that demonstrates how to chain AI language models together. It uses n8n's Advanced AI nodes to perform a creative multi-step task, utilizing the Google Gemini API.

## Workflow Details
The workflow consists of five nodes in total (two processing steps + two AI models + one trigger):
1. **Manual Trigger**: Starts the workflow.
2. **Generate Coffee Shop Names (Basic LLM Chain)**: The first AI step. It is prompted to act creatively and generate a list of 3 random names for a new coffee shop. 
   - *Connected to: Google Gemini Chat Model 1*
3. **Generate Slogans (Basic LLM Chain)**: The second AI step. It takes the exact output generated by the first AI step (using the expression `{{ $json.text }}`) and is prompted to write a catchy marketing slogan for those specific coffee shop names.
   - *Connected to: Google Gemini Chat Model 2*

## How to Import and Test
1. Open your n8n instance and create a new workflow.
2. Click the **Options menu (...)** in the top right > **Import from File**.
3. Select the `sequential_ai_workflow.json` file.
4. **Important**: Before testing, you must double-click the two **Google Gemini Chat Model** nodes and select your Google Gemini API credentials.
5. Click the **Test Workflow** button at the bottom of the screen.
6. Click on the final node ("Generate Slogans") and view the **Output** tab to see the final AI-generated slogans based on the initial AI-generated names!
